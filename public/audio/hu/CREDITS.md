# Recording credits

These recordings are redistributed from [Wikimedia Commons](https://commons.wikimedia.org/).
Each row links to the file's Commons page, which carries the full licence text
and history. Works under CC BY-SA are redistributed under the same licence.

They are used by the ear trainer; see `src/data/minimal-pairs.ts`, which holds
the same author and licence for each file so the app can show them.

The file names transliterate the Hungarian word (`á` → `aa`, `ö` → `oe`, `ű` →
`uee`, and so on), because a URL path cannot carry the accents reliably and
dropping them would collide the very pairs this is for: `hal` and `hál` must
not both be `hal.ogg`.
